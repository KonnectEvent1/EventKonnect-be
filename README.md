## Event Konnect

## Description

Event Konnect is a Rwanda-based innovative digital platform that simplifies and centralises the event planning process. We provide a one-stop solution that helps planners, vendors, and clients connect, collaborate, and execute events efficiently

## Dependencies
- Node (<=V18)
- Yarn (Package Manager),
- Nestjs (NodeJs Framework)
- sendGrid (Email API)

## Compile and run the project

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/Josiane705/Event-Konnect-be.git
   ```

2. **Install Dependencies**:

   ```bash
   yarn install
   ```
3. **Run Linting & formating**:
   ```bash
   $ yarn lint
   $ yarn format
   ```

3. **Run the Development Server**:
   ```bash
   $ yarn run start:dev
   ```
